# Twilight and You

개인용 Android 날씨·미세먼지·박명 위젯.

1×1에도 기온, 날씨 이모지, 미세먼지와 초미세먼지 각각의 색상, 지정 박명 시각을 함께 표시합니다. 가로형 2×1과 세로형 1×2도 지원합니다.

- 결정 기록: [DECISIONS](docs/DECISIONS.md)
- 원본 인수인계: [HANDOVER](docs/HANDOVER.md) — 최신 요구는 SPEC을 따릅니다.
