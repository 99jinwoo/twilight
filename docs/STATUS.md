# 구현·검증 상태

업데이트: 2026-10-07. 단계 B(레이아웃 검증) 진행 중. 첫 개인용 출시(E) 완료가 아니다.

## 구현한 내용

- Kotlin·Compose 단일 앱, Android 10 이상, 세 Glance 위젯(1×1·2×1·1×2).
- 기온·날씨 이모지·미/초 색상·선택한 박명 시각을 크기별 배치에 포함.
- 지역 이름·박명 기준·아침/저녁/다음 선택·색·불투명도·글자 크기를 위젯별 DataStore에 저장.
- 홈화면 추가, 구성 화면, 위젯 탭으로 재설정, 삭제 시 해당 설정 정리.
- 기본값은 미연결. 사용자가 샘플 표시를 켠 경우에만 가상의 값과 '샘플' 표기를 함께 표시.
- 1시간 WorkManager 작업은 화면 재표시만 수행한다. 실제 자료 다운로드 작업은 아직 없다.

## 검증 기록

- 로컬 `./gradlew lint test assembleDebug`: 실행 시도. 현재 권한의 로컬 소켓 제한(`SocketException: Operation not permitted`)으로 Gradle 초기화 실패. 통과 아님.
- Mac arm64 에뮬레이터: `init_cache_info`에서 SIGILL로 부팅 실패. 화면 검사 완료 아님.
- JVM 검사 7개: 먼지 경계값·결측·독립 등급·샘플 옵트인·박명 선택·크기 전환.
- 기기 검사 4개: 설정 유지/격리/삭제, 범위 제한, 실제 Glance RemoteViews 표시 및 잘림, 앱 실행.
- GitHub Actions 첫 실행(37573786002): lint·단위 검사·APK 빌드 통과. API 35 표시 검사에서 56×72dp의 기온+이모지 잘림을 발견했다. 배치를 수정하고 재검사한다.
- 앱 미리보기는 실제 홈 위젯과 동일한 Glance RemoteViews를 사용한다. 별도 모사 화면으로 배치 차이를 숨기지 않는다.
- Galaxy S24+·Note9 / Samsung One UI 실기기 검사: 미실시.

## 아직 구현하지 않은 출시 요구

기상청/에어코리아 실측·예보 통신, 수동 위치 확인, 지역 좌표/측정소 선택, 기기 박명 계산, 날짜 경계 처리, 실제 자료 캐시 및 갱신 표시, 재부팅/배터리 최적화 검사.

샘플의 10월 7일·17시·기온·먼지·박명은 배치용 고정 예시다. 천문 계산값이나 현재 자료가 아니다. '다음 박명'도 샘플 상황에서는 저녁을 가리키며 실제 시간 선택 로직은 단계 C에서 구현한다.

## 기기 확인 순서

1. 미리보기 APK를 설치하고 앱에서 크기·색·박명을 변경한다.
2. '홈 위젯에도 샘플 표시'를 켜고 세 위젯을 홈화면에 추가한다.
3. 각각 다른 지역·테마·박명을 저장하고 다른 위젯에 영향을 주지 않는지 확인한다.
4. 위젯 크기, 홈 격자, 시스템 글자 크기를 바꾸며 이모지·미/초 색·박명 시각 잘림을 확인한다.
5. 샘플을 끄면 가짜 값 대신 회색 결측·미연결이 보이는지 확인한다.
6. 앱 종료·재시작, 위젯 삭제/추가를 확인한다. 기본 글자 크기에서도 필수 항목이 잘리면 단계 B 미완료로 처리한다.
