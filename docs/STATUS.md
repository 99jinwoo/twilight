## v0.3.1 미세먼지 조회 수정

- 사용자 화면에서 기상청 실황·예보 수신과 현재 위치 사용을 확인했다. 사용자는 가까운 측정소 목록도 나온다고 답했다. 이후 새로고침으로 미세먼지 실측이 표시된다고 확인했다. 먼지 예보 정상 수신은 별도 미확인이다.
- 기존 측정소 적용/목록 선택은 설정만 바꾸고 조회하지 않았다. 이제 ‘적용 후 조회’와 목록 선택이 선택한 측정소로 즉시 요청한다. 다른 지역으로 바뀌면 이전 응답은 화면을 덮어쓰지 않는다.
- 기존 전송 계층은 HTTP 401/403/429 외 오류를 모두 NETWORK로 처리하고 오류 본문을 버렸다. 이제 JSON/XML 공공 게이트웨이 오류 본문을 먼저 분류하며 서버·시간초과·인증·보안연결·요청거절을 구별한다. HTTP/API 숫자 코드와 마지막 조회 시각만 저장·표시하고 키·URL·원문 메시지는 남기지 않는다.
- 자료가 한 번도 없을 때 ‘저장 자료를 표시합니다’, 조회 실패일 때 ‘미발표’라는 오해를 주던 안내를 바로잡았다. 측정소 검색 오류는 해당 버튼 옆에 표시한다.
- 로컬 `lint test assembleDebug assembleDebugAndroidTest` 및 Android 10/15 검사를 통과했다. 상세 수치는 위 최신 검증을 따른다.
- 사용자가 에어코리아 실측 수신을 확인했다. 예보 정상 수신은 미확인이다. 수정본은 확인된 조회 흐름과 진단 결함을 고친 것이며 공급자 오류의 복구를 보장하지 않는다.
- 맥 중계서버와 일반 공개 준비는 사용자 지시에 따라 차후 과업으로 둔다. 이번 수정에 서버를 추가하지 않는다.

- 좁은 가로 위젯에서도 오른쪽 네 행으로 네 시간 예보를 표시한다. 현재 위치 모드는 앱 실행·새로고침 때 좌표·측정소·예보권역을 갱신하며 실패하면 마지막 지역을 유지한다. 고정 지역 옵션과 닫힌 동안 마지막 위치 사용을 유지한다.

## v0.3.0 기반 구현

- 1×1·가로 2×1·세로 1×2 배치를 유지한다. 다음 박명은 위·굵게, 직전은 아래·보조색, 어제/오늘/내일을 붙인다.
- 선택 좌표로 시민·항해·천문박명을 기기에서 계산한다. 키·통신 없이 동작한다.
- 기상청 실황/시간별 예보, 에어코리아 PM10/PM2.5 관측과 오늘/내일 공식 예보의 연결 코드를 구현했다. 실황 기온·농도가 없으면 예보로 대입하지 않는다. SKY를 예보로 보충한 아이콘은 ‘예’로 구분한다.
- 앱에서 자료 종류·출처·관측/대상/발표/수신 시각·부분 실패를 확인한다. 관측 2시간 초과는 위젯에서 비우고 상세에 보존한다.
- 기본 4지역, 좌표 직접 지정, 현재 위치 1회 확인·적용, 예보권역 수동 선택, 가까운 측정소 5곳 제안·고정.
- API 키 기기 암호화 저장, 지역/측정소별 캐시, 중복 요청 공유, 실패 시 정상 자료 유지, 1시간 주기 갱신. 샘플은 명시적으로 켠 경우에만 전체를 가상 자료로 표시한다.

## 설치와 남은 일

[GitHub Releases](https://github.com/99jinwoo/twilight/releases)에서 APK를 제공한다. 아직 고정 배포 서명을 쓰지 않아 이전 미리보기와 서명이 다르다. 기존 앱을 삭제한 뒤 새 APK를 설치해야 하며 설정·홈 위젯·입력 키를 다시 구성한다.

사용자 보고로 v0.1은 Note9에서 정상 동작했다. v0.3의 Note9/S24+ 가독성·위치 확인·Samsung 런처·재부팅·절전·장시간 갱신은 별도 확인이 필요하다. 1시간 작업은 Android 때문에 늦어질 수 있어 박명 사건 직후/자정 직후 전환이 지연될 수 있다.

아직 남은 첫 출시 요구: 실제 인증·자료 확인, 업그레이드를 위한 고정 배포 서명, 재부팅/배터리/7일 사용 검증, 박명 전체 표와 일출몰 상세, 오늘/내일 최고최저, 갱신 간격 선택, 시스템 테마·0% 투명도·먼지색 재정의. 이번 APK를 최종 출시 완료로 표현하지 않는다.

키 신청·설정은 [API_SETUP](API_SETUP.md)을 따른다. 이전 v0.2 검증: 코드 `91ea895`, [CI 37625892199](https://github.com/99jinwoo/twilight/actions/runs/37625892199), 12개 단위 검사·API 29/35 각각 4개 기기 검사 통과.
