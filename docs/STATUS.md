# 구현·검증 상태

업데이트: 2026-10-07. 단계 B(레이아웃 검증) 진행 중. 첫 개인용 출시(E) 완료가 아니다.

## 구현한 내용

- Kotlin·Compose 단일 앱, Android 10 이상, 세 Glance 위젯(1×1·2×1·1×2).
- 기온·날씨 이모지·미/초 색상·선택한 박명 시각을 크기별 배치에 포함.
- 지역 이름·박명 기준·아침/저녁/다음 선택·색·불투명도·글자 크기를 위젯별 DataStore에 저장.
- 홈화면 추가, 구성 화면, 위젯 탭으로 재설정, 삭제 시 해당 설정 정리.
- 기본값은 미연결. 사용자가 샘플 표시를 켠 경우에만 가상의 값과 '샘플' 표기를 함께 표시.
- 1시간 WorkManager 작업은 화면 재표시만 수행한다. 실제 자료 다운로드 작업은 아직 없다.

- 작은 1×1의 이모지 잘림, 좁은 가로형의 안내 줄 잘림, 세로형 상태 줄 누락을 검사에서 발견해 수정했다.

- 로컬 Gradle은 처음 실행 환경의 소켓 제한으로 실패했고, Mac arm64 에뮬레이터는 부팅 전 SIGILL로 종료됐다. 최종 성공 기록은 GitHub의 Linux 빌드 및 Android 에뮬레이터 결과다.

- 설정 저장 검사는 DataStore의 영구 저장과 위젯 ID별 격리를 확인한다. 실제 다중 홈 위젯의 모든 수명주기 검사를 완료했다는 뜻은 아니다.

## 기기 확인 순서

1. 미리보기 APK를 설치하고 앱에서 크기·색·박명을 변경한다.
2. '홈 위젯에도 샘플 표시'를 켜고 세 위젯을 홈화면에 추가한다.
3. 각각 다른 지역·테마·박명을 저장하고 다른 위젯에 영향을 주지 않는지 확인한다.
4. 위젯 크기, 홈 격자, 시스템 글자 크기를 바꾸며 이모지·미/초 색·박명 시각 잘림을 확인한다.
5. 샘플을 끄면 가짜 값 대신 회색 결측·미연결이 보이는지 확인한다.
6. 앱 종료·재시작, 위젯 삭제/추가를 확인한다. 기본 글자 크기에서도 필수 항목이 잘리면 단계 B 미완료로 처리한다.
