# 구현·검증 상태

업데이트: 2026-10-08. v0.2.0-preview, 단계 B(레이아웃 검증). 실제 자료를 사용하는 첫 개인용 출시 완료가 아니다.

## 현재 구현

- Android 10 이상, Kotlin·Compose 설정 앱과 Glance 위젯 세 크기(1×1·가로 2×1·세로 1×2). 4×1은 사용자 확인상 오타여서 추가하지 않았다.
- 1×1은 100×112dp 칸 안의 카드 배경을 88×90dp로 축소했다. 기온·이모지·미/초미 독립 색, 다음 박명(위·굵게), 직전 박명(아래·작은 보조색)을 표시한다. '샘플 17시' 줄은 제거했다.
- 박명 이름 앞에 어제/오늘/내일 표시. 한국 현재 시각으로 직전 ≤ 현재 < 다음을 선택하며, 고정 아침/저녁 모드 UI는 제거했다. 기존 저장 필드는 호환용으로 보존했다.
- 2×1 오른쪽에 시간별 예보 최대 4개, 폭 170~209dp는 3개, 더 좁으면 2개. 1×2 아래에 4개 행. 모두 날짜·시각·아이콘·기온 포함.
- 지역 이름·박명 기준·테마·불투명도·글자 크기·샘플 여부를 위젯 ID별 저장한다. 홈화면 추가·재설정·설정 삭제와 1시간 재표시 작업을 제공한다.
- 홈 위젯 기본값은 미연결이다. 사용자가 샘플을 켠 경우에만 가상 값을 표시한다. 앱 미리보기·설정·배포 안내에 샘플임을 명시한다.

## 실기기와 설치

- 사용자 보고: v0.1.0-preview가 Note9에서 정상 동작한다. OS 버전·홈 격자·장시간 동작은 보고에 포함되지 않았으므로 별도로 단정하지 않는다.
- v0.2.0의 Note9/S24+ 가독성, Samsung 런처 추가/삭제/크기 조절, 시스템 큰 글자, 재부팅·배터리·장시간 갱신은 별도 확인이 필요하다.
- v0.2 APK의 테스트 서명이 v0.1과 다르므로 이전 미리보기를 삭제한 뒤 새로 설치해야 한다. 삭제 시 설정·홈 위젯이 사라지므로 다시 추가한다. 정식 배포용 고정 서명으로 전환하지 않았다.
- 설치 파일은 [GitHub Releases](https://github.com/99jinwoo/twilight/releases/tag/v0.2.0-preview)에서 다운로드한다.

## 아직 구현하지 않은 출시 요구

기상청/에어코리아 실측·예보 통신, 수동 위치 확인, 지역 좌표/측정소 선택, 실제 천문 박명 계산, 실제 자료 캐시와 기준시각·오래됨 표시, 재부팅/배터리 최적화 검사.

샘플 기온·먼지·박명 시각·시간별 날씨는 가상 자료다. 현재 한국 시각으로 사건 순서와 날짜를 선택하지만 천문 계산 결과가 아니다. 앱 미리보기와 홈 위젯은 같은 Glance 표시 코드를 사용한다. 위젯은 마지막 갱신 시각에 선택한 사건을 표시하며 1시간 주기·OS 지연으로 사건 직후나 자정 직후 전환이 늦을 수 있다.
