## 2026-10-07 · 확인 사실

- GitHub 연결에서 `99jinwoo/twilight` 읽기·쓰기 권한을 확인했다. 저장소는 공개 상태이며 비어 있다.
- 첨부의 초기 계획은 비공개 저장소였지만 현재 가시성을 바꾸라는 사용자 요청은 없었다. 가시성은 변경하지 않았다.
- 공공데이터포털의 기상청·에어코리아 서비스 본문을 확인했다. 인증키 보유 여부와 실제 API 호출 결과는 미확인이다.
- SPEC v0.1과 이번 이력은 로컬 문서로 작성했다. 원격 커밋·푸시·PR·앱 코드 작성은 하지 않았다.
- 2026-10-06 보완 기획의 실측 후속 도입·세로형 우선·1×1 분리 제안은 D001~D003으로 대체한다.

## SPEC 승인 기록

2026-10-07: 사용자가 SPEC 초안과 구현 순서를 확인한 뒤 “진행합시다”라고 지시했다. SPEC v0.1을 기준으로 저장소 구성·Android 프로젝트·세 위젯 배치 구현을 시작한다. P001~P008은 변경 가능한 초기 설계값으로 채택한다. 실제 자료 연결과 실기기 검증 완료를 뜻하지 않는다.

## 2026-10-07 · 위젯 기반 구현

- 단계 B에서는 자료 연동 없이 배치를 검증한다. 홈 위젯 기본값은 미연결, 샘플은 사용자 옵트인이다. 앱 미리보기에는 항상 샘플 안내를 붙인다.
- AGP 8.13.2 / Gradle 8.13 / JDK 17 / Kotlin 2.2.21, compile/targetSdk 36으로 고정했다. 호환 기준: [AGP 공식 릴리스 노트](https://developer.android.com/build/releases/agp-8-13-0-release-notes).
- Compose BOM 2025.10.01·Activity Compose 1.11.0은 설정/미리보기, Glance 1.2.0은 홈 위젯, DataStore 1.1.7은 위젯별 영구 설정, WorkManager 2.10.1은 주기적인 재표시에 사용한다. 네트워크 의존성은 아직 추가하지 않는다.
- JUnit 4.13.2와 AndroidX Test 1.6.1/1.6.2·JUnit 확장 1.2.1은 경계값 및 실제 기기의 설정/RemoteViews 검사용이다.
- 이번 미리보기는 불투명도 100%, 저녁 테마를 기본으로 한다. 투명도 25~100%와 세 테마만 구현했고, SPEC의 0%·시스템 테마·먼지색 재정의는 후속 단계다. 좁은 1×1은 필수 항목 유지를 위해 요청한 글자 크기를 줄일 수 있다.
- GitHub Actions와 Android Emulator Runner를 사용해 API 29/35 자동 검사를 구성한다. 샘플 화면 검사가 삼성 실기기 검증을 대체하지는 않는다.
- 최초 문서 작성 시점의 '로컬만 작성' 기록 이후, 승인 문서를 main에 올리고 구현은 feat/widget-foundation 브랜치에서 진행했다. 최신 검증 상태는 STATUS를 따른다.
