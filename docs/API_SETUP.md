# 실제 날씨·먼지 연결

v0.3.2-preview / 2026-10-09

박명은 키 없이 계산한다. 날씨·먼지는 아래 서비스를 신청한 본인의 공공데이터포털 인증키가 필요하다. 키를 대화나 GitHub에 붙이지 말고 앱에 입력한다.

## 신청과 앱 설정

1. [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do), [에어코리아 대기오염정보](https://www.data.go.kr/data/15073861/openapi.do), [에어코리아 측정소정보](https://www.data.go.kr/data/15073877/openapi.do)를 각각 활용 신청한다. 가까운 측정소 검색에는 세 번째 서비스 승인도 필요하다.
2. 포털에서 서비스별 승인 상태와 일반 인증키를 확인한다. 승인 반영에 시간이 걸리면 포털 안내에 따른다. 기상청·에어코리아에 같은 일반키가 적용되는 계정이면 두 칸에 같은 키를 입력할 수 있다.
3. 앱에서 고정 지역을 선택한다. 기본 서울·부산·제주·강릉 외에는 ‘직접 지정’ 또는 ‘현재 위치 한 번 확인’을 사용하고 먼지 예보권역을 확인한다.
4. ‘실제 자료 → API 연결’에서 기상청·에어코리아 키를 입력하고 ‘저장 후 연결’을 누른다. 인코딩/디코딩 키를 모두 처리한다. 빈 칸은 기존 키를 유지한다.
5. 측정소는 자동 선택된다. 현재 위치 또는 고정 지역에서 가까운 PM10·PM2.5 측정소를 찾아 바로 조회하므로 이름 입력이나 목록 선택은 필요하지 않다. 특정 측정소를 원할 때만 ‘측정소 변경 (선택 사항)’을 열어 직접 선택한다.
6. ‘새로고침’을 누르고 관측시각·예보 발표시각·수신 상태를 확인한다. 홈 위젯 편집으로 열었다면 ‘이 위젯으로 저장’을 눌러 지역·측정소 선택을 반영한다. 샘플 표시는 꺼둔다.

현재 위치를 따라가려면 ‘지역과 위치 → 앱 실행·새로고침 때 현재 위치’를 켜고 ‘앱 사용 중’ 위치 권한을 허용한다. 홈 위젯에서 열었다면 ‘이 위젯으로 저장’을 누른다. 이후 앱 실행·전경 복귀·새로고침 시 좌표와 가까운 측정소·예보권역을 갱신하며, 앱을 닫으면 마지막 확인 위치로 날씨를 갱신한다. 현재 위치 모드로 저장된 다른 위젯도 확인한 위치를 공유하고 고정 지역 위젯은 유지한다. 위치 실패 시 마지막 지역을 유지한다. 장소가 크게 바뀐 뒤 주소·측정소를 못 찾으면 이전 지역 자료와 섞지 않는다. 같은 장소에서 검색만 실패하면 마지막 측정소를 유지한다. 옵션을 끄거나 지역을 직접 지정하면 고정 지역으로 돌아간다.

## 표시의 뜻

- 기온: 기상청 격자의 초단기실황. 개인 좌표에서 직접 측정한 기온이 아니다.
- 날씨: 실황 강수를 우선한다. 강수가 없을 때 가까운 시간의 단기예보 SKY를 보충하면 아이콘에 ‘예’를 붙이며 앱에 그 대상·발표시각을 표시한다. 정보가 없으면 물음표다.
- 미/초미: 선택된 측정소의 한 시간 관측 농도. 점검 플래그가 있으면 숫자가 있어도 결측 처리한다. 앱 색상 분류와 공식 예보등급은 별개다.
- 시간별 날씨: 다음 정시부터 위젯 최대 4시간, 앱 향후 24시간. 예보 발표시각을 함께 확인한다.
- 먼지 예보: 오늘/내일의 지역별 PM10·PM25 공식 등급. 발표·대상 날짜를 구별하고 임의의 미래 농도로 바꾸지 않는다.
- 관측 2시간 초과: 위젯에서는 빈 값, 앱에서는 이전 값과 ‘오래된 자료’. 박명은 네트워크 실패와 관계없이 계산한다.

## 실패 시 확인

| 앱 표시 | 확인할 내용 |
|---|---|
| 인증키 미설정 | API 연결에서 키 저장 |
| 키 또는 서비스 승인 상태 확인 | 오타·해당 서비스 활용 승인·포털의 활성 상태 |
| 측정소 선택 | 측정소 이름 적용 후 새로고침 |
| 호출 한도 초과 | 포털 할당량 확인, 나중에 재시도 |
| 아직 발표되지 않았거나 자료 없음 | 최신 발표 지연·측정소 결측 가능. 기준시각 확인 |
| 네트워크 연결 실패 / 보안 연결 실패 | 인터넷·VPN 등 연결 환경 확인. 다른 정상 자료는 유지 |
| 공공 API 서버 오류 / 응답 시간 초과 | 공급자 응답 확인. 잠시 후 다시 조회하고 계속되면 HTTP/API 숫자 코드를 알려주기 |
| 응답 형식 확인 불가 | 공급자 응답 변경 가능. 키를 빼고 화면의 상태만 알려주기 |

수동 요청은 같은 자료당 최소 1분, 자동 재시도는 최소 15분 간격이다. 기본 위젯 갱신은 1시간이며 Android 절전으로 늦어질 수 있다. 통신 실패 시 기존 캐시를 보존하되 그 자료를 새 관측으로 표시하지 않는다.

## 구현·검증 범위

기상청 20260928 가이드, 에어코리아 대기오염정보 v1.4·측정소정보 v1.2 첨부를 확인했다. JSON/XML 오류, 페이지 분할, 시간/발표본 선택, 결측, 캐시 격리·부분 실패는 모의 응답으로 검사한다. 사용자가 기상청 수신과 새로고침 후 에어코리아 실측 표시를 확인했다. 2026-10-09 사용자 S24+ 화면에서 위치·주소·예보권역과 두 먼지의 오늘/내일 예보 수신을 확인했다. 새 측정소 검색 방식의 실제 시간 초과 해소와 위젯 가독성은 설치 후 추가 확인이 필요하다.

키는 AndroidKeyStore로 암호화해 앱 전용 백업 제외 영역에 저장하며 키 입력창은 화면 캡처를 차단한다. API 응답 캐시에는 허용된 공개 자료 필드만 남긴다. ‘연결 정보와 저장 자료 지우기’로 제거할 수 있다. 이 키는 앱 서명키와 별개이며 GitHub로 업로드하지 않는다.

측정소 목록이 나와도 대기오염정보 서비스의 실측·예보 승인이 보장되는 것은 아니다. 문제가 계속되면 해당 서비스 활용승인 상태와 ‘측정소별 실시간 측정정보 조회’·‘대기질 예보통보 조회’ 기능 선택을 확인한다. 오류 화면의 HTTP/API 숫자 코드는 공유할 수 있지만 키와 요청 URL은 공유하지 않는다.

측정소 검색 실패는 1분 뒤 재시도할 수 있다. 앱이 열린 동안 일시적인 연결 실패는 65초 간격으로 최대 두 번 자동 재시도하며 GPS를 다시 요청하지 않는다. 인증·할당량 오류는 짧은 재시도에서 제외한다. 앱을 닫아도 기존 위젯 주기 갱신에서 마지막 위치 기준으로 자동 선택을 다시 시도한다.
